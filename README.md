# C++ 交互式课堂

一个可直接双击打开的中文 C++ 教学网站。它沿用参考站的「上方四区可视化 + 下方教程卡片 + 右侧交互实验台」形式，把工作区两份文档中的内容整理成 7 章、25 节课程。

## 打开方式

直接双击 `index.html`，或用浏览器打开：

```text
cpp-interactive-tutorial/index.html
```

不需要安装依赖、不需要构建、不需要联网。课程进度会保存在当前浏览器的 `localStorage` 中。

## 课程内容

| 章节 | 主题 |
| --- | --- |
| 第 1 章 | 从 C 结构体到类：为什么需要类、第一个 `Motor` 类 |
| 第 2 章 | 封装：`public` / `private`、不变量、成员函数、`class` 与 `struct` |
| 第 3 章 | 构造、对象与 `const`：构造函数、多对象、对象指针、只读成员函数 |
| 第 4 章 | 指针与引用：引用参数、值/指针/引用的选择 |
| 第 5 章 | 链表：数组对照、节点、遍历、插入删除、栈/堆与所有权 |
| 第 6 章 | 滑动窗口滤波：原理、环形缓冲、C 实现、工程取舍 |
| 第 7 章 | 综合项目、测试、速查表与结课测验 |

## 交互方式

- 顶部四区会随当前课程和实验台操作同步变化：源码、对象模型、内存视图、运行输出。
- 右侧实验台是**教学模拟器**，不是真实 C++ 编译器；它按 C++ 语义模拟对象、访问控制、指针、链表示意和滑动窗口状态。
- 支持四种实验台模式：
  - `Motor`：构造对象、`setSpeed`、`enable`、`const` 对象、对象指针。
  - `LinkedList`：`traverse`、`head`、`find`、`insertAfter`、`removeAfter`。
  - `MovingAverage`：`push`、`pushMany`、`demo`、`status`。
  - `Pipeline`：`update`、`demo`、`status`。
- 输入 `help` 可查看当前模式支持的命令；`reset` 重置当前实验台；`clear` 清空终端。
- 任务栏会检查输入的语句或测验答案，完成后自动记录，侧边栏显示完成状态。

## 文件结构

```text
cpp-interactive-tutorial/
├── index.html       页面结构
├── style.css        全部样式与响应式布局
├── js/
│   ├── content.js   课程数据、代码高亮、内容辅助函数
│   └── app.js       导航、四区渲染、实验台模拟器、进度与测验
└── README.md
```

## 修改课程

- 课程文案、代码块、测验题都在 `js/content.js` 的 `chapters` 数组中。
- 每张卡片支持 `viz`（可视化类型）、`lab`（实验台模式）、`snippet`（源码区片段）、`focus`（高亮行号）、`task`（任务步骤）和 `quiz`（测验）。
- 颜色、字号和布局变量集中在 `style.css` 顶部的 `:root`。

## 说明

- 示例代码以 C++17 为目标；链表与滤波章节同时保留了文档中的 C 写法，并补充了 C++ 对照。
- `const` 对象、私有成员错误、空指针解引用等由模拟器按教学目的展示，实际编译器报错文本可能不同。
- 页面不依赖外部字体或 CDN；离线也能完整使用。
